# 國立自然科學博物館 × 國家衛生研究院
## 《看見你我他牠它：健康一體的行動密碼》特展成果教學平台

本專案將國立自然科學博物館（科博館）現場 105 張高解析度實拍展板與展品照片，經數位影像校正、雜邊去除、色彩增強與深度內容結構化，建構為一套符合「通用訪視成果技能」標準 4+1 架構之現代化響應式單頁成果教學展示平台（SPA）。

## 💻 本機離線運行指引 (Local Runbook)

本系統為純靜態單頁應用程式，無須安裝 Node.js、Apache 或任何後端資料庫：

1. **一鍵啟動**：
   在 Windows 檔案總管中，直接雙擊 `start_local.bat`。
2. **自動開啟瀏覽器**：
   系統將自動於本機 Port 8000 啟動 Python HTTP 伺服器，並於預設瀏覽器開啟：
   `http://localhost:8000`
3. **雲端託管**：
   亦可直接部署於 GitHub Pages 或 Netlify，開箱即用。

## ⌨️ 簡報投影模式常用快捷鍵 (Keyboard Shortcuts)

* **翻頁**：`PageDown` / `Space` / `→` 下一頁；`PageUp` / `←` 上一頁。
* **全螢幕**：按 `F` 鍵進入全螢幕沉浸投影。
* **講稿備忘**：按 `N` 鍵開關講者備忘錄面板。
* **畫筆工具**：按 `D` 鍵或 `P` 鍵開啟／關閉正下方微型畫筆工具列；按 `Esc` 退出。
* **燈箱操作**：在照片燈箱中，按 `Esc` 退出，按 `←` / `→` 切換上／下一張相片。
