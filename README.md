# 看見生命的連線｜臺中自然科學博物館訪視成果

這是一個以工作區現有照片製作的公開展示／教學成果頁。主題以「從微觀到宏觀，看見生命的連線」串聯展場導入、互動學習、微觀生命、健康與防護、生物多樣性等內容。

## 專案結構

- `index.html`：展示頁結構、主題文字與無障礙標籤
- `styles.css`：響應式版面、字級／背景主題、列印樣式
- `app.js`：照片分類資料、篩選、搜尋、燈箱、觀察任務與列印功能
- `PXL_*.jpg`：原始訪視照片；網站不覆蓋原檔，使用前端裁切與懶載入呈現

## 使用方式

1. 直接以瀏覽器開啟 `index.html`。
2. 若瀏覽器限制本機 JavaScript，可在此資料夾啟動簡易伺服器：

   ```powershell
   python -m http.server 8000
   ```

3. 開啟 `http://localhost:8000/`。

## 已完成的整理

- 從 105 張原始照片挑選 35 張代表影像作為公開頁精選圖庫。
- 以「展場導入、微觀生命、健康與防護、生物多樣性、互動與學習」分類。
- 每張照片加入可調整的標題、描述與觀察提示，適合課堂提問或導覽。
- 使用 CSS `object-fit` 與 `object-position` 進行展示端裁切，不破壞原始照片。
- 提供中／大／特大字級、淺／深／綠／藍背景、主題篩選、搜尋、燈箱與列印觀察單。

## 客製化

- 要新增照片：在 `app.js` 的 `photos` 陣列新增 `[檔名, 分類代碼, 分類名稱, 標題, 說明, 觀察提示]`。
- 要調整照片裁切：在 `styles.css` 修改 `.hero-photo-main img` 或 `.photo-card img` 的 `object-position`。
- 要修改主題色：調整 `styles.css` 的 `:root` 或 `body[data-theme=...]` CSS 變數。
- 要加入全部 105 張照片：可依原始檔名批次產生 `photos` 陣列，再以相同欄位補上分類與教學文字。
